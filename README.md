# Ball Battle

เกมต่อสู้อัตโนมัติ ตัวละครเด้งไปมาในสนามแล้วสู้กันเอง ใช้สกิลเองตามคูลดาวน์ ตัวละครเป็นไฟล์ PNG ที่สลับท่าตอนใช้สกิล
เขียนด้วย HTML + JavaScript ล้วน ไม่ต้องติดตั้งอะไร

## เล่นในเครื่อง

เปิด `index.html` ในเบราว์เซอร์ได้เลย ถ้าภาพไม่ขึ้น (บางเบราว์เซอร์บล็อกไฟล์ในเครื่อง) ให้รันเซิร์ฟเวอร์เล็กๆ:

```bash
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```

## เอาขึ้น GitHub Pages

1. สร้าง repo ใหม่บน GitHub แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (ให้ `index.html` อยู่ที่ราก repo)
2. ไปที่ Settings > Pages
3. ที่ Source เลือก "Deploy from a branch" แล้วเลือก branch `main` โฟลเดอร์ `/ (root)` กด Save
4. รอสักครู่ จะได้ลิงก์รูปแบบ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

## เพิ่มตัวละครของตัวเอง

1. เตรียม PNG พื้นหลังโปร่งใส ขนาดเท่ากัน (แนะนำสี่เหลี่ยมจัตุรัส เช่น 256x256) ให้ตัวละครหันหน้าไปทาง **ขวา**
   เกมจะกลับด้านให้อัตโนมัติเมื่อศัตรูอยู่ฝั่งซ้าย
2. ใส่ไว้ที่ `assets/characters/<ชื่อตัวละคร>/` เช่น `idle.png` และท่าสกิล เช่น `shoot.png`
3. เปิด `js/characters.js` แล้วคัดลอกบล็อกของตัวละครเดิมมาแก้
   - `frames` ชี้ไปที่ไฟล์ PNG แต่ละท่า (ต้องมี `idle`)
   - `skill.frame` คือท่าที่จะสลับไปใช้ตอนใช้สกิล และ `skill.duration` คือกี่วินาทีที่ท่านั้นค้างอยู่
4. รีเฟรชหน้าเว็บ ตัวละครใหม่จะโผล่ในรายการให้เลือกเอง

ถ้าไฟล์ PNG โหลดไม่ได้ เกมจะวาดเป็นบอลสีแทน เลยเทสระบบได้ก่อนวาดภาพจริง

### ชนิดสกิลที่มีให้

**กติกา: ตัวละครชนกันแค่เด้งออกจากกัน ไม่เกิดดาเมจ ดาเมจมาจากสกิลเท่านั้น** ตัวละครหนึ่งตัวมีกี่สกิลก็ได้ (`skills: [ ... ]`) แต่ละสกิลมีคูลดาวน์ของตัวเอง

| type | ทำอะไร | ค่าที่ปรับได้ |
|---|---|---|
| `projectile` | ยิงกระสุนหรือโน้ตใส่ศัตรู ยิงเป็นชุดได้ | `damage`, `projectileSpeed`, `projectileRadius`, `fireDelay`, `count`, `interval`, `spread`, `shape` (`ball`/`note`), `wobble`, `sound` |
| `dash` | พุ่งเข้าหาศัตรู ชนครั้งแรกในการพุ่งแต่ละครั้งทำดาเมจและทำให้กระเด็น | `damage`, `speedMult`, `homing`, `knockback` |
| `shockwave` | ปล่อยคลื่นเสียงเป็นส่วนโค้งแผ่ไปทางศัตรู โดนแล้วกระเด็น | `damage`, `waveSpeed`, `waveRange`, `waveArcDeg`, `knockback` |

คำอธิบายแต่ละค่าอยู่ในคอมเมนต์ด้านบนของ `js/characters.js`

อยากได้สกิลชนิดใหม่ ให้เพิ่มเงื่อนไขใน `_updateSkill` ที่ `js/battle.js`

## เสียง

เสียงทั้งหมดสร้างจากโค้ดด้วย Web Audio จึงไม่ต้องมีไฟล์เสียงและไม่ต้องกังวลเรื่องลิขสิทธิ์

| เสียง | เล่นเมื่อ |
|---|---|
| click | กดปุ่ม / เปลี่ยนตัวละคร |
| start | กด "เริ่มสู้" |
| shoot | ยิงกระสุน |
| hit | โดนสกิลของศัตรู |
| note | โน้ตดนตรีของ Singer |
| wave | คลื่นเสียงของ Singer |
| dash | พุ่ง |
| ko / win / draw | จบการต่อสู้ |

- เบราว์เซอร์จะเริ่มเล่นเสียงได้หลังผู้เล่นกดปุ่มครั้งแรกเท่านั้น (เกมปลดล็อกให้ตอนกดปุ่ม)
- ปุ่ม "เสียง" ใช้เปิด/ปิด และจำค่าไว้ในเบราว์เซอร์
- อยากใช้ไฟล์เสียงของตัวเอง ให้เปิด `js/audio.js` แล้วแก้เมธอดแต่ละเสียงให้เล่น `new Audio("assets/sfx/xxx.mp3").play()` แทน

## โครงไฟล์

```
index.html            หน้าเกม
style.css             หน้าตา
js/characters.js      ข้อมูลตัวละครและสกิล (แก้บ่อยที่สุด)
js/battle.js          ตรรกะการต่อสู้ (ฟิสิกส์ ดาเมจ สกิล)
js/audio.js           เสียงทั้งหมด (สร้างจากโค้ด ไม่มีไฟล์เสียง)
js/main.js            วาดภาพ เอฟเฟกต์ และปุ่มต่างๆ
assets/characters/    ไฟล์ PNG ของตัวละคร
```

## เรื่องภาพ

ภาพตัวอย่างในโฟลเดอร์ `assets/` เป็นภาพที่วาดขึ้นเองสำหรับทดสอบ ถ้าจะใช้ภาพ stock ให้ตรวจสิทธิ์การใช้งานของภาพนั้นก่อน
โดยเฉพาะถ้าจะเผยแพร่เกมต่อสาธารณะ

## ฟอนต์และขนาดสนาม

- ฟอนต์ที่ใช้คือ Prompt จาก Google Fonts (รองรับภาษาไทย) โหลดผ่านลิงก์ใน `index.html` ถ้าออฟไลน์หรือโหลดไม่ได้ เกมจะใช้ฟอนต์ของระบบแทนเอง
- สนามเป็นสี่เหลี่ยมจัตุรัส 720x720 ปรับได้ที่ `width`/`height` ของ `<canvas>` ใน `index.html` (หลอดเลือดและตำแหน่งเริ่มต้นปรับตามขนาดอัตโนมัติ)
- เมื่อจบแมตช์ ตัวที่แพ้จะแตกเป็นเศษภาพจาก PNG ของตัวเอง ส่วนคนชนะยังเด้งไปมาต่อ

## อัปเดตเกมบน GitHub Pages แล้วยังเห็นของเก่า?

GitHub Pages และเบราว์เซอร์แคชไฟล์ JS/CSS ไว้นาน อาจทำให้ไฟล์ใหม่บางตัวทำงานคู่กับไฟล์เก่า (เช่นแตกกระจายได้แต่คนชนะไม่เด้ง)
เกมนี้จึงมีตัวช่วยสองอย่าง

- ท้ายสนามมีบรรทัด "เวอร์ชัน N" ถ้าไฟล์ใน `js/` ตัวไหนเป็นเวอร์ชันเก่าหรือไม่ได้อัปโหลด จะขึ้นกรอบแดงบอกชื่อไฟล์นั้น
- ชื่อไฟล์ใน `index.html` ลงท้ายด้วย `?v=N` เพื่อบังคับให้เบราว์เซอร์ดึงไฟล์ใหม่

เวลาแก้โค้ดแล้วอยากให้ผู้เล่นได้ของใหม่ ให้เพิ่มเลขเวอร์ชันพร้อมกัน 3 จุด: `?v=` ใน `index.html`, `EXPECTED_VERSION` ใน `js/main.js`
และบรรทัด `BB_FILES ... = N` ท้ายไฟล์ `characters.js`, `battle.js`, `audio.js`

## แผงข้อมูลผู้เล่นและคูลดาวน์ (v6)

- ชื่อ หลอดเลือด (มีตัวเลข) ชื่อสกิล และแถบคูลดาวน์ อยู่ในแผง HTML เหนือสนาม ไม่ได้วาดทับในสนามแล้ว
- แถบคูลดาวน์นับถอยหลังเป็นวินาที เช่น `1.1 วิ` เมื่อพร้อมจะเป็นสีเขียว "พร้อมใช้!" และเป็นสีส้ม "กำลังใช้สกิล!" ตอนกำลังใช้
- ก่อนกด "เริ่มสู้" แผงจะโชว์ค่าคูลดาวน์ของตัวละครที่เลือก เช่น `คูลดาวน์ 1.6 วิ`
- ชื่อสกิลที่โชว์ ตั้งได้ที่ `name` ของแต่ละสกิลใน `js/characters.js` ถ้าตัวละครมีหลายสกิล แผงจะโชว์แถบคูลดาวน์ของทุกสกิล
- สนามจะย่อให้พอดีจออัตโนมัติ โดยหักความสูงของแผงข้อมูลออกก่อน

## Singer: ใส่ภาพของตัวเองตรงไหน

Singer มีภาพชั่วคราวที่ฉันวาดไว้ให้แล้ว ใส่ภาพของคุณ**ทับชื่อไฟล์เดิม**ได้เลย ไม่ต้องแก้โค้ด

| ไฟล์ | ใช้ตอนไหน |
|---|---|
| `assets/characters/singer/idle.png` | ท่ายืนปกติ (เด้งไปมา) |
| `assets/characters/singer/sing.png` | ท่าร้องเพลง ตอนปล่อยโน้ต (ค้างราว 1 วินาที) |
| `assets/characters/singer/wave.png` | ท่าตะโกน/กระแทกคลื่นเสียง (ค้างราว 0.6 วินาที) |

เงื่อนไขของภาพ
- เป็น PNG พื้นหลังโปร่งใส ขนาดเท่ากันทั้งสามไฟล์ (แนะนำสี่เหลี่ยมจัตุรัส เช่น 256x256 หรือ 512x512)
- ตัวละครหันหน้าไปทาง **ขวา** เกมจะกลับด้านให้เองเวลาศัตรูอยู่ฝั่งซ้าย
- จัดตัวละครให้อยู่กลางภาพ และให้ตำแหน่งเท้า/ลำตัวคล้ายกันทั้งสามท่า ภาพจะได้ไม่กระตุกตอนสลับท่า
- โน้ตดนตรีและคลื่นเสียง**เกมวาดให้เองด้วยโค้ด** ไม่ต้องใส่ในภาพ ถ้าอยากให้ท่า `wave.png` มีเส้นคลื่นเสียงประกอบก็ใส่เองได้

ถ้าอยากใช้ชื่อไฟล์อื่น หรืออยากเพิ่มท่าเพิ่ม ให้แก้ `frames` และ `frame` ของสกิลใน `js/characters.js`
ถ้าไฟล์ภาพโหลดไม่ได้ เกมจะวาด Singer เป็นบอลสีม่วงแทน (เช็กชื่อไฟล์ว่าตัวพิมพ์เล็ก/ใหญ่ตรงกันหรือไม่)

ปรับความแรงของ Singer ที่ `js/characters.js` ในบล็อก `singer`: `damage` ของโน้ต (ต่อโน้ต 1 ตัว), `count` (จำนวนโน้ตต่อครั้ง), `cooldown` และ `damage`/`knockback`/`waveArcDeg` ของคลื่นเสียง
